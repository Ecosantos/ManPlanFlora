# Management plans bias the number of threatened species in protected areas


This repository contains the supplementary data for the study on Atlantic Forest flora species published in **Biodiversity & Conservation**. Access the full paper here: [DOI: 10.1007/s10531-024-02796-y](https://link.springer.com/article/10.1007/s10531-024-02796-y)

## Repository Structure

- `index.qmd`: The primary Quarto document containing the reproducible workflow for the interactive map production.
- `Supplementary material 2.html`: An interactive HTML report providing the final cleaned dataset (downloadable) and spatial visualizations of the study areas.
